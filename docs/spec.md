# Browser Tool Contract

The host registers one tool through `defineTool` and persists screenshot bytes through the official attachment service. Context ownership is the Harness session ID. Operations serialize within a session and preserve isolation between sessions. Input consumes an observation counter and exact accessibility locator, or observed coordinates when a target has no accessible name. Inspections are fixed functions returning redacted structured values. Abort closes the owning context. Disposal closes all contexts and Chromium.

The client registers one `browser` page type through `ctx.sidebarRightTabs` and renders it through the keyed `sidebar.right.pane.tab` slot. The page is an authenticated view of the same Session-scoped Playwright page exposed by the Host endpoints. `/api/dsh-browser` answers one-shot reads, pointer and keyboard input, navigation and scroll; `/api/dsh-browser/stream` holds one authenticated newline-delimited JSON response open and pushes the picture plus interaction cues. Frames come from a CDP screencast, so a still page produces no traffic and an action updates the pane immediately; the queue keeps only the newest frame, and the endpoint starts and stops the screencast with its first and last reader. Pointer events carry the acting side, so the pane labels a human click differently from an Agent click. Hover probes read `elementFromPoint` and never consume an observation. Focus events carry the focused box, role, name and editability, which drives the pane's outline, caption and caret.

The pane reflows to the Sidebar's own size and reconnects its stream on a settled resize, which resizes the Host viewport. It shares cookies, storage, login state and page history with the `browser` tool, falls back to one-shot captures when the stream is unavailable, and re-attempts the stream while in that fallback. The Host process remains headless and the right Sidebar supplies the visible surface. The implementation uses only official client plugin APIs and does not patch Harness source.
