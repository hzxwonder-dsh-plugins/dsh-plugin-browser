# Browser Tool Contract

The host registers one tool through `defineTool` and persists screenshot bytes through the official attachment service. Context ownership is the Harness session ID. Operations serialize within a session and preserve isolation between sessions. Input consumes an observation counter and exact accessibility locator. Inspections are fixed functions returning redacted structured values. Abort closes the owning context. Disposal closes all contexts and Chromium.

The client registers one `browser` page type through `ctx.sidebarRightTabs` and renders it through the keyed `sidebar.right.pane.tab` slot. The page accepts only credential-free HTTP(S) addresses, starts at the local Harness URL, and uses a sandboxed iframe. It does not share cookies, storage, or a Playwright page with the host tool. Sites that deny framing remain unsupported by the page and are handled by the independent tool. The implementation uses only official client plugin APIs and does not patch Harness source.
